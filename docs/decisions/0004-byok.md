# 0004 — Bring your own keys

**Status:** accepted; Anthropic part superseded by 0007

**Context.** LLM + transcription costs scale with use; a hackathon can't pay for users.

**Decision.** Users supply transcription (Deepgram/AssemblyAI/Groq) and optional Wispr
keys (Anthropic moved to a server-wide token in 0007). AES-GCM encrypted with `ENCRYPTION_KEY`, stored in `user_keys` (secret-key client only),
validated on save, never returned to the browser (last 4 via `user_keys_public`).

**Consequences.** No provider billing for us. Onboarding has a key-entry step. Losing/rotating
`ENCRYPTION_KEY` means users re-enter keys. Details: `docs/auth-and-keys.md`.
