# Design system

Linear-style product UI: quiet, dense, fast, keyboard-first. Content is the loudest thing on
screen. Hierarchy comes from 1px borders and background steps, never shadows. Review everything at
`/dev/ui` (dev only, no sign-in needed).

## Tokens (`apps/web/src/app.css`)
Raw tokens live on `:root`. Dark is the only theme; `<html class="dark">` is set in `app.html`. A
light theme later = one block redefining the raw tokens. Never use raw hex in components.

| Token | Value | Use | Tailwind |
|---|---|---|---|
| `--bg-canvas` | #101114 | App background | `bg-background` / `bg-canvas` |
| `--bg-surface` | #17181C | Sidebar, panels, cards | `bg-card` / `bg-surface` / `bg-sidebar` |
| `--bg-elevated` | #1F2026 | Popovers, modals, hover rows | `bg-popover` / `bg-muted` / `bg-elevated` |
| `--border` | #2A2B32 | Default 1px border | `border` (default color) |
| `--border-strong` | #3A3B44 | Focused/active containers | `border-border-strong` |
| `--text` | #E8E8EC | Primary text | `text-foreground` |
| `--text-muted` | #8B8C96 | Secondary text, metadata | `text-muted-foreground` |
| `--accent` | #F5C842 | Primary button, focus ring, active nav, playhead, selection | `bg-primary` / `bg-accent` / `ring-ring` |
| `--accent-fg` | #1A1500 | Text on yellow | `text-primary-foreground` |
| `--success` | #4CC38A | Done | `text-success` |
| `--danger` | #F2555A | Failed, destructive | `text-danger` / `destructive` |
| `--info` | #5E9EFF | Processing | `text-info` |
| `--warning` | = accent | Warnings | `text-warning` |

shadcn semantic vars (`--background`, `--primary`, `--sidebar-*`, …) are mapped onto these in
`app.css`. **`accent` means yellow everywhere.** Stock shadcn uses `bg-accent` for hover rows, so
generated components were rewritten to use `bg-elevated` instead, and overlay blur was replaced
with a flat `bg-black/50` (see the `add-ui-component` skill). `shadcn-svelte/tailwind.css` (imported in
`app.css`) supplies the `data-open:`, `data-checked:`, `data-active:` … variants the components use.

### Yellow budget
At most **one primary (yellow) button per view**, plus focus rings, the active-nav indicator,
playhead and selection. Never use yellow for large fills, body text or decoration. Status uses
`StatusBadge`, not a yellow `Badge`.

## Type
- UI: Hanken Grotesk 400/500/600 (`@fontsource`, imported in `routes/+layout.svelte`).
- Mono: JetBrains Mono, **only** for timecodes, durations and IDs (`font-mono`, `Timecode`).
- Scale (Tailwind classes remapped): `text-xs` 12 · `text-sm` 13 (base UI, body default) ·
  `text-base` 14 · `text-lg` 16 · `text-xl` 20 (page title) · `text-2xl` 24.
- Sentence case everywhere. No all-caps labels, no eyebrow labels above headings, no arrows
  appended to buttons.

## Radius, shadow, motion
- `rounded-sm` 4px (inputs, badges, kbd) · `rounded-md` 6px (buttons, menu items) ·
  `rounded-lg` 8px (panels, popovers, dialogs). Avatars/switches/sliders stay round.
- Shadows are removed at the theme level (`--shadow-*: initial`), so `shadow-*` classes do nothing.
- Motion only in response to a user action (open, expand, confirm) or as a live-state signal (the
  processing pulse). A global `prefers-reduced-motion` block zeroes animations and transitions.
- Icons: `@lucide/svelte`, 16px (`size-4`) by default, stroke 1.5 (global `.lucide` rule).

## Components
Generated by shadcn-svelte into `$lib/shared/ui/<name>` (aliases in `apps/web/components.json`):
avatar, badge, breadcrumb, button, calendar, command, dialog, dropdown-menu, empty, input,
input-group, kbd, label, popover, scroll-area, select, separator, sheet, sidebar, skeleton,
slider, sonner, switch, table, tabs, textarea, tooltip.

Ours, in `$lib/shared/ui`:
| Component | API | Notes |
|---|---|---|
| `PageHeader` | `title`, `description?`, `actions?` snippet | `text-xl` title |
| `EmptyState` | `icon`, `text`, `action?: {label, href? \| onclick?}` | One sentence, at most one (primary) action |
| `StatusBadge` | `status: JobStatus` | pending muted · processing info + pulse · needs_input accent outline · done success · stopped muted + slash icon · failed danger |
| `Timecode` / `formatTimecode` | `seconds` | `01:23.4`, `1:02:03.5`; mono, tabular numbers |
| `DataTable` | `columns: Column<T>[]`, `rows`, `empty?` snippet, `onrowclick?` | Click header to sort asc → desc → none; hover row `bg-elevated` |
| `TopbarActions` | children | Puts page actions in the top bar (renders after hydration) |
| Kbd | shadcn `kbd` as-is | `Kbd.Root`, `Kbd.Group` |

Toasts: `toast()` from `svelte-sonner`; `<Toaster />` is mounted in the root layout.

## App shell (`$lib/widgets/app-shell`)
- Sidebar (shadcn `sidebar`, `collapsible="icon"`, state in the `sidebar_state` cookie, read on
  the server so there's no flash). Items come from `$lib/shared/config/nav.ts` (`sidebar: true`).
  The active item gets `bg-elevated` + a 2px yellow left bar. Clip picker/Editor/Publish highlight
  Queue. Footer: avatar menu (Account, Sign out).
- Top bar: breadcrumbs (`crumbsFor()` in `nav.ts`), `TopbarActions` slot, search button (⌘K).
- Command palette (⌘/Ctrl+K): every nav route, "New job", "Open settings".
- Shortcuts, defined only in `$lib/shared/config/shortcuts.ts`: ⌘K palette · ⌘B sidebar ·
  `?` shortcut sheet · `G` then `H/Q/C/B/S` → Home/Queue/Calendar/Brand memory/Settings.
  Ignored while typing in inputs.

## Do / don't
- Do use tokens and shared components; check `/dev/ui` before building something new.
- Do keep one primary button per view; everything else is `outline`, `ghost` or `secondary`.
- Do give empty states real copy that says what to do next.
- Don't use raw hex, shadows, gradients, glass/blur, decorative illustrations or idle animation.
- Don't use mono for labels, all-caps, eyebrow labels or "→" on buttons.
